# 业务规则

- 订单以（租户, 订单标识）唯一；重复受理必须被拒绝且不改变已存在单据。
- 未收金额 = 订单金额 − 已收金额；收款不得超过未收金额。
- 跨租户读取一律按“不存在”处理，不得泄漏对象是否存在。
- 金额以最小货币单位的整数表示，不使用浮点数。
- 每笔收款与冲正都必须留痕，记录含业务流水标识、操作类型、金额、发生时间与发起方标识；同一订单的流水按发生顺序返回。
- 冲正只能作用于属于当前租户、且属于该订单的收款记录；冲正金额等于原收款金额，不支持部分冲正；同一笔收款只能冲正一次。
- 冲正为原子操作：冲正成功后订单的已收/未收金额与状态必须与从未发生该笔收款一致（已结清的订单冲正后回到未结清）；冲正记录通过原流水标识与原收款关联，可据此重建因果链。
- 订单不存在、流水不存在、跨租户、重复冲正、冲正后金额不合法等失败必须可区分，且任一失败都不得改动账面与流水；同一冲正请求重放只生效一次。
- 订单可受理一份分期计划：每期含期次标识、应收金额与到期时间；各期应收之和必须等于订单金额，期次标识不得重复，金额必须为正，任一条不合法则整份计划被拒绝且不留任何一期；同一订单的计划只能受理一次，重复受理返回冲突且不改动已受理计划。
- 受理分期计划后，登记收款必须声明期次且金额等于该期应收；收讫后该期标记为已收，订单已收/未收与状态按原有规则推进，全部期次收讫时订单结清；未声明期次、金额不等、期次不存在、期次已收讫、未受理计划却按期次收款均为可区分的拒绝，且不改动账面与留痕。
- 对分期收款的冲正必须连同对应期次退回未收，冲正后账面、期次状态与该笔收款从未发生完全一致；冲正仍只能整笔撤销且同一笔收款只能冲正一次。
- 分期计划与每期收讫状态必须可查询；跨租户查询一律按不存在处理。
- 同一期次被并发收款时至多一笔成功，其余返回冲突且不重复留痕；同一收款或冲正请求重放只生效一次，账面、期次状态与流水留痕始终闭合，因果链可按流水标识重建。

# 业务规则

- 订单以（租户, 订单标识）唯一；重复受理必须被拒绝且不改变已存在单据。
- 未收金额 = 订单金额 − 已收金额；收款不得超过未收金额。
- 跨租户读取一律按“不存在”处理，不得泄漏对象是否存在。
- 金额以最小货币单位的整数表示，不使用浮点数。
- 收款冲正按（租户, 冲正标识）唯一；冲正金额必须大于 0，且不得超过订单当前已收金额，已收金额不得被任何一次请求变为负数。
- 冲正只作用于本租户名下的订单；订单不存在或属于其他租户时一律按“不存在”处理。
- 同一冲正标识重复提交且业务内容（订单标识、冲正金额）与首次一致时，只产生一次冲正效果并返回成功；业务内容不一致时拒绝（409）且不改变账务。
- 订单状态口径统一为：已收金额达到订单金额为“已结清（settled）”，低于订单金额（含 0）为“未收清（accepted）”；登记收款与冲正都按此口径回算状态。
- 收款与冲正在单个数据库事务内完成，冲突时整体回滚，不留下半截账务。
- 每一次成功生效的收款或冲正在同一事务内追加一条流水，按生效先后关联到订单；流水记录操作类型、本次金额、操作后的已收金额、未收金额与订单状态，冲正流水另记冲正标识。被拒绝的请求与重复提交的冲正标识不产生流水；已有流水只增不改，重启后顺序与内容保持不变。
- 流水查询只返回本租户名下订单的流水；订单不存在或属于其他租户一律按“不存在”处理。

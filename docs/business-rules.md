# 业务规则

- 订单以（租户, 订单标识）唯一；重复受理必须被拒绝且不改变已存在单据。
- 未收金额 = 订单金额 − 已收金额；收款不得超过未收金额。
- 跨租户读取一律按“不存在”处理，不得泄漏对象是否存在。
- 金额以最小货币单位的整数表示，不使用浮点数。
- 每笔收款与冲正都只追加留痕为一条流水，含业务流水标识、操作类型、金额、发生时间、发起方标识；同一订单按发生顺序读取。
- 冲正只能针对属于本租户、本订单且类型为收款的流水；冲正金额等于原收款金额，不支持部分冲正。
- 同一笔收款只能冲正一次，重复冲正（含请求重放）必须拒绝，账面与流水只反映一次冲正。
- 冲正后订单的已收金额、未收金额与状态必须与该笔收款从未发生完全一致；曾因收款变为已结清的，冲正后回到未结清。
- 冲正记录通过原流水标识与原收款关联，可据此重建因果链；任何失败都不得改动账面或流水（事务原子性）。

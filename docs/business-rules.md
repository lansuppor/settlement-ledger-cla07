# 业务规则

- 订单以（租户, 订单标识）唯一；重复受理必须被拒绝且不改变已存在单据。
- 未收金额 = 订单金额 − 已收金额；收款不得超过未收金额。
- 跨租户读取一律按“不存在”处理，不得泄漏对象是否存在。
- 金额以最小货币单位的整数表示，不使用浮点数。
- 收款冲正按（租户, 冲正标识）唯一；冲正金额必须大于 0，且不得超过订单当前已收金额，已收金额不得被任何一次请求变为负数。
- 冲正只作用于本租户名下的订单；订单不存在或属于其他租户时一律按“不存在”处理。
- 同一冲正标识重复提交且业务内容（订单标识、冲正金额）与首次一致时，只产生一次冲正效果并返回成功；业务内容不一致时拒绝（409）且不改变账务。
- 订单状态口径统一为：已收金额达到订单金额为“已结清（settled）”，低于订单金额（含 0）为“未收清（accepted）”；登记收款与冲正都按此口径回算状态。
- 收款与冲正在单个数据库事务内完成，冲突时整体回滚，不留下半截账务。
- 每次成功生效的收款登记或冲正都形成一条收款流水，按订单维度以递增序号记录生效先后；同类型多次操作以订单内唯一的流水标识区分。
- 每一次成功生效的收款登记或冲正都记录一个业务发生时间，最小精确到秒、带时区偏移。调用方可在收款/冲正请求中以 `business_time` 自行提供本次业务发生时间（必须是带时区偏移的完整日期时间、到秒；提供合法时按该时间记账）；未提供时由服务按当前时间记账。非法的业务发生时间按参数错误拒绝，不改变账务、不产生流水。服务统一换算为 UTC 基准时刻存储，同一时刻的不同时区写法等价，不因写法不同重复记账或漏记；读回（流水清单与区间查询）时保留登记时的偏移写法，服务自行记账的记录以服务当前时间的偏移写法返回。
- 流水保留本次操作类型（收款/冲正）、本次金额（最小货币单位整数）、操作后的已收金额、未收金额与订单状态、业务发生时间；冲正流水另关联当次冲正标识，可从流水定位到那次冲正。
- 流水只追加、不重排、不改写：重复提交的冲正标识（幂等成功）不产生新流水；被拒绝的收款与冲正不产生流水，也不改变已有流水的内容与顺序。
- 流水按订单标识查询，租户通过请求头传入；只返回本租户名下订单的流水，订单不存在或属于其他租户一律按“不存在”处理，不得泄漏对象是否存在。
- 支持按业务发生时间范围查询某订单在一段时间内生效的收款与冲正：起点与终点都必填、必须为合法的完整日期时间（到秒、带时区偏移），且起点不得晚于终点；参数缺失、非法或起点晚于终点时返回可区分的参数错误，且在读取任何数据之前完成校验。
- 范围查询以业务发生时间为准、闭区间（两端点等于边界值时包含对应流水），只返回区间内生效的全部流水，早于起点或晚于终点的流水不得混入；结果按生效先后排列，与收款流水清单的顺序口径一致，各条流水内容与清单完全一致（业务发生时间按登记时的偏移写法返回）。区间内无流水或订单尚无收款/冲正时返回空结果；订单不存在或属于其他租户一律按“不存在”处理。
- 支持按订单标识与对账时区偏移出具按日汇总：起点与终点都必填、必须为合法的完整日期时间（到秒、带时区偏移），起点不得晚于终点；对账时区偏移必填，为 `Z` 或 `±HH:MM` 写法；参数缺失、非法或起点晚于终点时返回可区分的参数错误，且在读取任何数据之前完成校验。
- 按日汇总先按业务发生时间的 UTC 基准时刻做闭区间取数（边界值恰在起点或终点时计入，早于起点或晚于终点不计入任何分组），再把每条流水换算到对账偏移后按其日历日归组；区间内每条流水恰计入一个日分组，跨日、跨时区不重复、不漏计。每组返回该日收款合计、冲正合计、流水条数，以及组内最早与最晚业务发生时间（按对账偏移写法）；无流水的日期不出现，结果按日期升序。各组条数之和等于区间内流水条数，收款与冲正合计分别等于对应流水金额之和。区间内无流水或订单尚无收款/冲正时返回空结果；订单不存在或属于其他租户一律按“不存在”处理。
- 支持按订单标识与对账时区偏移出具按月汇总：起点、终点与对账时区偏移的取值规则与按日汇总一致（起点终点必填、为到秒且带时区偏移的完整日期时间，起点不得晚于终点；偏移必填，为 `Z` 或 `±HH:MM` 写法）；参数缺失、非法或起点晚于终点时返回可区分的参数错误，且在读取任何数据之前完成校验。
- 按月汇总与按日汇总同一取数口径：先按业务发生时间的 UTC 基准时刻做闭区间取数，再把每条流水换算到对账偏移后按其日历日所在年月归组；区间内每条流水恰计入一个月分组，跨月、跨时区不重复、不漏计。每组返回该月收款合计、冲正合计、流水条数，以及组内最早与最晚业务发生时间（按对账偏移写法）；无流水的月份不出现，结果按月份升序。各组条数之和等于区间内流水条数，收款与冲正合计分别等于对应流水金额之和；同一偏移下与按日汇总闭合：各月合计与条数等于该月内各日分组之和，日分组不跨月重复或漏计。区间内无流水或订单尚无收款/冲正时返回空结果；订单不存在或属于其他租户一律按“不存在”处理。
- 流水随数据库持久化，服务重启后顺序、金额、各次操作后的账务快照与业务发生时间（基准时刻与登记时偏移写法）保持不变；此后新的收款与冲正继续在末尾追加，各自携带自身的业务发生时间。按日、按月汇总均由持久化流水实时汇总得出，服务重启后汇总结论保持不变。

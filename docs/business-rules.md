# 业务规则

## 订单与收款

- 订单以（租户, 订单标识）唯一；重复受理必须被拒绝且不改变已存在单据。
- 未收金额 = 订单金额 − 已收金额；收款不得超过未收金额。
- 跨租户读取一律按“不存在”处理，不得泄漏对象是否存在。
- 金额以最小货币单位的整数表示，不使用浮点数。

## 退款单

- 退款单是独立单据，以（租户, 退款单标识）唯一；租户通过请求头声明。
- 受理退款单要求：金额为正整数；原订单存在且属于本租户（否则一律按“不存在”返回，不泄漏订单是否存在）；订单已结清，即未收金额为 0；退款金额 ≤ 可退余额，可退余额 = 订单金额 − 累计已退金额。
- 任一受理条件不满足都拒绝受理，拒绝原因可区分，且不得留下任何部分生效的数据。
- 同一（租户, 退款单标识）重复受理不得重复入账，也不得改变首次受理的单据；超时重试只命中同一次受理结论。
- 退款只改写订单的累计已退金额，不改写未收金额与收款记录。订单暴露累计已退金额与当前可退余额，满足：累计已退 + 可退余额 = 订单金额。

## 冲正（退款单）

- 只有处于已受理（accepted）状态的退款单可冲正；冲正把该退款金额从累计已退金额中整体退回，退款单进入已冲正（reversed）状态。
- 对已冲正退款单重复冲正、对未受理标识（含跨租户）冲正，分别返回可区分的拒绝原因，且不改变订单与退款单的任何数据。
- 冲正之后同一退款单标识不得再次受理。

## 结算单

- 结算单是独立单据，以（租户, 结算单标识）唯一；租户通过请求头声明。
- 受理结算单要求：金额为正整数；原订单存在且属于本租户（否则一律按“不存在”返回，不泄漏订单是否存在）；订单已结清，即未收金额为 0；未发生任何退款，即累计已退金额为 0；结算金额 ≤ 剩余可结算金额，剩余可结算金额 = 订单金额 − 已受理结算金额之和（不含已冲正部分）。
- 任一受理条件不满足都拒绝受理，拒绝原因可区分（订单不存在 / 未结清 / 已有退款 / 超过剩余可结算金额 / 重复受理 / 已冲正），且不得留下任何部分生效的数据。
- 同一（租户, 结算单标识）重复受理不得重复入账、重复占用订单金额，也不得改变首次受理的单据；超时重试只命中同一次受理结论。
- 结算单受理后可分期收款：累计收款不得超过结算单的结算金额，超限拒绝且不改动结算单；每次收款后暴露累计已收与未收金额（未收 = 结算金额 − 累计已收）。
- 结算单受理后允许冲正：仅 accepted 且累计已收为 0 的结算单可冲正；冲正后进入 reversed 状态并整体释放其占用的订单剩余结算金额；存在任何收款时冲正必须被拒绝（与“未受理/已冲正”原因可区分），订单与结算单保持不变；冲正之后同一结算单标识不得再次受理。
- 结算只改写订单的累计已结算金额与结算单自身的累计已收，不改写已收金额、收款记录、累计已退金额。订单暴露累计已结算金额与剩余可结算金额，满足：累计已结算 + 剩余可结算 = 订单金额。

## 并发与持久化

- 同一退款单标识并发受理最多一个成功，其余请求得到拒绝且账务不重复；并发受理不同退款单时累计已退不得超过可退余额。
- 同一结算单标识并发受理最多一个成功，其余得到拒绝且金额不重复占用；不同结算单并发受理时累计已结算不得超过订单剩余可结算金额；同一结算单并发分期收款累计已收不得超过结算金额。
- 受理与冲正（含结算单收款）的判定和入账在单个数据库事务内原子完成，失败整体回滚。
- 已受理与已冲正状态在服务重启后仍可判定，重启后仍可继续收款、冲正或受理新的结算单与退款。

# 业务规则

- 订单以（租户, 订单标识）唯一；重复受理必须被拒绝且不改变已存在单据。
- 未收金额 = 订单金额 − 已收金额；收款不得超过未收金额。
- 跨租户读取一律按“不存在”处理，不得泄漏对象是否存在。
- 金额以最小货币单位的整数表示，不使用浮点数。
- 退款单以（租户, 退款单标识）唯一，作为独立单据受理；重复受理必须被拒绝，首次受理的内容不得被改写。
- 退款仅可针对已结清订单（未收金额为 0）；可退余额 = 订单金额 − 累计已退金额，退款金额不得超过可退余额。
- 退款不改变订单的已收金额与未收金额；累计已退金额 + 当前可退余额恒等于订单金额。
- 退款单受理（accepted）后可整体冲正（reversed），冲正退回其累计已退金额；已冲正不可再次冲正，同一标识冲正后不得再次受理。
- 受理与冲正的全部判定与写入在单个即时事务内完成；并发或重试下同一标识最多产生一次金额变动，失败不留部分数据，状态持久化可跨重启判定。

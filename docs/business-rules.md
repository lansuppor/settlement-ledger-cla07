# 业务规则

- 订单以（租户, 订单标识）唯一；重复受理必须被拒绝且不改变已存在单据。
- 未收金额 = 订单金额 − 已收金额；收款不得超过未收金额。
- 收款冲正按（租户, 冲正标识）幂等：同一标识只产生一次冲正效果；重复提交且业务内容（订单标识、冲正金额）一致时返回与首次一致的成功结果，内容不一致时拒绝且不改账。
- 冲正只能作用于本租户名下存在的订单；订单不存在或属于其他租户按不存在处理。
- 冲正金额必须大于 0 且不得超过订单当前已收金额；任何单次请求都不得把已收金额变为负数。
- 冲正成功后扣减已收金额、未收金额等额增加；已收金额低于订单金额回到 `accepted`，达到订单金额为 `settled`。收款登记遵守同一状态口径。
- 收款与冲正在单个请求内原子提交；订单、收款与冲正记录持久化落库，重启后重复冲正标识仍不会二次扣减。
- 跨租户读取一律按“不存在”处理，不得泄漏对象是否存在。
- 金额以最小货币单位的整数表示，不使用浮点数。
